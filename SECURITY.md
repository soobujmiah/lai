# Security policy

Please report vulnerabilities privately through GitHub Security Advisories for this repository. Do not open a public issue containing an exploit, secret, private screenshot, accessibility dump, signing material, or device identifier.

Include the affected commit/tag, Android version, whether Accessibility or Shizuku was enabled, reproduction steps, impact, and the smallest redacted evidence possible.

Phase 1 is pre-production. The most important report areas are confirmation bypass, arbitrary command execution, package/argument injection, password/screenshot disclosure, unsafe exported components, model-path/file validation, JNI memory safety, and CI secret leakage.

See [docs/SECURITY_AND_SAFETY.md](docs/SECURITY_AND_SAFETY.md) for the threat model and known gaps.
