# Product roadmap

The canonical, complete Phase 0–14 roadmap is maintained in [`../ROADMAP.md`](../ROADMAP.md).

That document contains, for every phase:

- objective;
- current and target state;
- dependencies and deliverables;
- architecture, security, and privacy requirements;
- tests and documentation gates;
- acceptance criteria;
- rollback and migration considerations.

This compatibility path exists because the master development directive requires `docs/product/roadmap.md`. Keeping the roadmap body in one canonical file prevents the root roadmap and product roadmap from drifting.
