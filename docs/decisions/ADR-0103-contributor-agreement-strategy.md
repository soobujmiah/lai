## Technical review status

## Context

[`../../CONTRIBUTING.md`](../../CONTRIBUTING.md) has no inbound copyright terms. Comparison of structures is in [`../legal/CONTRIBUTOR_LICENSING_POLICY.md`](../legal/CONTRIBUTOR_LICENSING_POLICY.md).

## Problem

Uncontrolled inbound Apache-2.0 contributions can later block relicensing of those files. Implementing a CLA now is out of scope.

## Options

No CLA; DCO; individual CLA; corporate CLA; assignment; inbound license agreement.

## Decision

**DECISION REQUIRED.** None implemented.

## Consequences

Status quo remains Apache-2.0 §5. Agents must not add CLA/DCO enforcement.

## Security implications

None.

## Privacy implications

Signed CLA records would be personal data if later collected.

## Licensing implications

No inbound change.

## Migration

If adopted later, apply to future submissions unless a historical assignment is executed.

## Alternatives rejected

Silent implementation of a CLA in this phase.
