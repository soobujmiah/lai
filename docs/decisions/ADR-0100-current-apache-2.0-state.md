# ADR-0100 — Current Apache-2.0 state

## Status

Accepted as a record of present fact. Not a relicensing decision.

## Date

2026-08-18

## Decision owner

Unassigned. **OWNER DECISION REQUIRED** for any change to this state.

## Legal review status

Not required to *record* the current license. **LEGAL REVIEW REQUIRED** before any change to [`../../LICENSE`](../../LICENSE).

## Technical review status

Source and GitHub metadata inspected. See [`../LEGAL_AND_LICENSING.md`](../LEGAL_AND_LICENSING.md).

## Context

The public repository declares Apache License 2.0. Releases and commits have been published under that declaration.

## Problem

Future commercial planning must not overwrite or misstate the current grant.

## Options

### Option A

Record the current Apache-2.0 state and leave the license file unchanged.

### Option B

Change the license now.

## Decision

Option A. [`../../LICENSE`](../../LICENSE) remains Apache License 2.0. Historical tags remain as published.

## Consequences

Recipients of published copies have the rights stated in that license. Those rights are not revoked by later documentation.

## Security implications

None beyond existing notice and signing practices.

## Privacy implications

None.

## Licensing implications

This ADR is the decision-record pointer to the current grant.

## Migration

None.

## Alternatives rejected

Option B is forbidden in this documentation phase and would not retroactively lock down published copies.
