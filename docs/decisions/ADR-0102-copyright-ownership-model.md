# ADR-0102 — Copyright ownership model

## Status

## Date

## Technical review status

Git identities inventoried. No ownership conclusion.

## Context

The only copyright line is `Copyright 2026 LAI contributors`. Commit authors include human-looking identities and bot/agent identities. See [`../legal/OWNERSHIP_MODEL.md`](../legal/OWNERSHIP_MODEL.md).

## Problem

Commercial relicensing of owner-controlled *new* work needs a defined owner. Inventing that owner in documentation would be false.

## Options

Status quo; named natural person; future company for new work; assignment of historical work; exclusive inbound license.

## Decision

**DECISION REQUIRED.** Bot and AI-agent identities are recorded as tooling, not copyright owners. No company is asserted.

## Consequences

Exclusive control of the historical tree is not established. New entity-owned modules remain possible after instruments exist.

## Security implications

None.

## Privacy implications

None.

## Licensing implications

Apache-2.0 §5 remains the inbound default.

## Migration

None until an instrument exists.

## Alternatives rejected

Listing AI agents as authors-for-copyright. Treating GitHub hosting as assignment.
