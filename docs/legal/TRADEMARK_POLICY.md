## Distinct categories

| Category | Covers | Current LAI record |
|---|---|---|
| Copyright | Original works (source, docs, original icon) | `Copyright 2026 LAI contributors` in [`../../LICENSE`](../../LICENSE) |
| License | Permission to use a work | Apache-2.0 for the published Work |
| Trademark | Names, logos, product identity in commerce | **Unverified** |
| Patent | Inventions | None recorded |
| Trade secret | Keys, unpublished algorithms, customer data | [`../security/COMMERCIAL_SECRET_POLICY.md`](../security/COMMERCIAL_SECRET_POLICY.md) |

Copyright licensing does **not** automatically grant trademark rights. Apache-2.0 section 6 grants no trademark license except reasonable origin description and NOTICE reproduction.

Public open-source publication of code therefore does not make the name “LAI”, the original icon, or future store listing identity freely available as marks. Conversely, a later trademark filing does not relicense Apache-2.0 code.
