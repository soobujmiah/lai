LAI does not commit model weights, SDKs, native binaries, APKs, or keystores. Every new dependency, model, backend, plugin package, dataset, converted artifact, creative asset, or distribution channel requires license/provenance review in the same change. Production release remains blocked on exact resolved notices, SBOM, provenance, checksums, permanent signing, and unknown-license policy.
